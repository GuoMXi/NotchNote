# NotchNote
把脑子里的事，暂放在刘海里。NotchNote 是一款原生 macOS 菜单栏便笺：暖白色纸张、黑色刘海外壳、自由书写和轻量待办。

## 使用

- 鼠标移到刘海下方的金色小横条，展开速览；离开面板约 350 毫秒后自动收起。编辑和切换项目后也遵循这一规则。
- 点击「点击开始写」或正文进入编辑。需要长时间保持面板时，点击顶部图钉固定，再点击恢复自动收起。
- `Control + Option + 空格`：随时展开编辑，再按一次收起。
- 进入编辑或点击「继续写」时会激活便笺并将键盘焦点交给编辑框，键盘唤出后可以直接输入；鼠标进入面板再离开才触发自动收起。中文输入法组词、拖动选择、格式弹窗和导出窗口操作期间暂停自动收起。
- `Esc`：收起。中文输入法组词时优先处理输入法，不关闭便笺。
- 鼠标开合时，纸张从刘海下缘抽出并原路收回（240 毫秒）；文字不会缩放或重新排版。过渡中可以反向操作，键盘开合保持即时响应。系统启用「减少动态效果」时使用轻淡入淡出。
- `Command + Shift + L` 或底部方框按钮：把光标所在行转为待办，再按一次恢复普通文本。
- 点击「勾选待办」进入可勾选预览，点击圆圈完成任务；「继续写」回到编辑。
- 编辑区上方可加粗、斜体、下划线（`⌘B`、`⌘I`、`⌘U`）；点击 `Aa` 调整字体、字号和文字颜色。选中文字时作用于选区，未选中时作用于后续输入。
- 右侧彩色索引签切换项目，每次只显示一个栏目，标签上显示各自的待办数；「继续写」编辑当前栏目。
- 索引签下方 `+` 可添加栏目；栏目较多时索引区支持独立滚动。重启后恢复最后选择的栏目。
- 内容和文字格式自动保存在本机，勾选待办、切换栏目和重启后均保留。底部导出按钮或菜单栏「导出便笺」默认导出包含所有栏目的 `.rtf` 富文本；也可以使用 `.txt` 后缀导出纯文本。

### 近期会议自动汇总

在项目内把光标放到会议所在行，点击格式栏的「会议」或按 `⌘⇧M`，这一行会自动显示到「近期会议」。再次点击可取消标记；普通正文出现“会议”两个字不会被自动归类。也可以直接输入 `#会议 讨论议程` 或 `- [ ] #会议 讨论议程`（标记后有空格）。

「近期会议」统一显示直接记录和来自项目的会议。未完成的会议按所选日期时间先后排序，未设时间的放在其后，已完成的放在最后；项目名保持小号文字，与会议同一行。点击来源或会议正文会进入原文编辑，勾选完成会同步到项目。

### 会议日期与提醒

- 在编辑区把光标放到会议所在行，点格式栏的「时间」；普通行选定时间后会自动标记为会议。也可以在项目预览或「近期会议」里点该行的「设时间」/已有日期。
- 在日历中选日期，调整具体时间，默认不提醒。可选会议开始时，或提前 5、10、15、30、60 分钟、1 天提醒。日期时间按 Mac 当前时区显示，保存后即时重新排序。
- 时间与提醒独立保存在本机，修改标题、插入前面的行和切换完成状态会保留会议时间。删除会议或取消会议标记会取消计划；复杂且无法确定归属的批量改写会清除相应时间，避免提醒错行。「清除时间」保留会议正文与标记。
- 首次主动启用提醒时才请求 macOS 通知权限；拒绝后仍可保存日期与排序，之后可在系统设置 → 通知 → NotchNote 中开启。改期会替换原提醒，完成、删除、关闭提醒或清除时间后撤销对应通知。已过去的提醒时间不会补发。
- 提醒通过系统本地通知发送，应用正常退出前会完成同步；点击通知可打开来源会议。系统通知受通知权限、专注模式和系统休眠等设置影响。本功能不读取或写入系统日历，也不会把便笺发送到服务器。

在「近期会议」点击「直接写会议」或「继续写」可以独立记录，点击「查看汇总」返回总览。编辑区只编辑直接记录的内容，已有直接记录保留。原文里的日期文字不会自动猜测成年月日；使用日历选定后才参与时间排序。

每个栏目独立保存文字和编辑撤销历史，支持自由换行、中文输入、复制粘贴。不与系统「便笺」同步；已有文字可以直接粘贴。编辑时的待办格式为 `- [ ] 内容`，完成后为 `- [x] 内容`。

## 构建

需要 macOS 14+ 和 Swift 6.2+（Xcode 或 Command Line Tools），无需第三方依赖。

```sh
zsh scripts/build-app.sh
open build/NotchNote.app
```

应用默认不显示 Dock 图标，通过菜单栏图标访问或退出。生成的应用使用本机临时签名；此版本尚未做 Developer ID 签名、公证或公开发行。

```sh
zsh scripts/check.sh
zsh scripts/check-motion.sh
zsh scripts/check-meetings.sh
```

回归检查覆盖中文与空行保留、待办切换、持久化、损坏文件保护、写入失败、显示器定位、原生编辑器行转换、富文本格式保存与导出；无需额外安装测试运行器。

窗口检查需要图形桌面会话，会短暂显示测试面板；使用独立的临时便笺数据，验证收起点击区域、反向过渡、键盘中断、栏目撤销隔离、格式选区保持、自动收起与固定/弹窗保护，以及失焦后编辑器第一响应者恢复、修改保存与重读、长文本滚动至末行及删短后的滚动区域收缩。

会议专项检查使用临时文件和模拟通知，覆盖日期排序与重启、行编辑后的绑定、改期与取消、权限拒绝、安排失败、原生日期触发器与异步请求竞争；不会弹出权限框或发送真实通知。

## 数据与边界

数据文件：`~/Library/Application Support/NotchNote/note.json`。使用原子写入；保存失败会显示提示，退出前会提醒备份。读取失败时保护原文件，暂停覆盖写入，可以导出当前输入内容后人工修复数据文件。

升级到栏目版时，旧便笺的独立 `【栏目名称】` 行会自动转为索引签，其他正文保留在对应栏目；未分组的文字放入「随手记」。转换前先生成完整原文件备份 `note.v1-<UUID>.json`，再写入新版格式。私人便笺数据不进入源码仓库。

优先附着在带刘海的显示器；没有刘海时位于主显示器菜单栏下方。显示器变化时重新定位。速览不激活当前应用，编辑通过原生浮动面板获取键盘输入。快捷键注册失败时提供菜单栏入口。

待实机验收：不同刘海机型、自动隐藏菜单栏、全屏 Space、外接显示器组合与 VoiceOver。当前未实现栏目删除与重命名、开机自启、iCloud 同步和系统便笺导入。
