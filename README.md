# NotchNote
把脑子里的事，暂放在刘海里。NotchNote 是一款原生 macOS 菜单栏便笺：暖白色纸张、黑色刘海外壳、自由书写和轻量待办。

## 使用

- 鼠标移到刘海下方的金色小横条，展开速览；离开面板约 350 毫秒后自动收起。编辑和切换项目后也遵循这一规则。
- 点击「点击开始写」或正文进入编辑。需要长时间保持面板时，点击顶部图钉固定，再点击恢复自动收起。
- `Control + Option + 空格`：随时展开编辑，再按一次收起。
- 进入编辑或点击「继续写」时会激活便笺并将键盘焦点交给编辑框，键盘唤出后可以直接输入；鼠标进入面板再离开才触发自动收起。中文输入法组词、拖动选择、格式弹窗和导出窗口操作期间暂停自动收起。
- `Esc`：收起。中文输入法组词时优先处理输入法，不关闭便笺。
- 鼠标开合时，纸张从刘海下缘抽出并原路收回（240 毫秒）；文字不会缩放或重新排版。过渡中可以反向操作，键盘开合保持即时响应。系统启用「减少动态效果」时使用轻淡入淡出。
- `Command + Shift + L` 或底部方框按钮：把光标所在行转为待办，再按一次恢复普通文本。
- 点击「勾选待办」进入可勾选预览，点击圆圈完成任务；「继续写」回到编辑。
- 编辑区上方可加粗、斜体、下划线（`⌘B`、`⌘I`、`⌘U`）；点击 `Aa` 调整字体、字号和文字颜色。选中文字时作用于选区，未选中时作用于后续输入。
- 右侧彩色索引签切换项目，每次只显示一个栏目，标签只保留栏目名称，待办数显示在当前页标题右侧；「继续写」编辑当前栏目。
- 「随手记」用于零散小任务与临时想法，点击即进入编辑；一行一件事，可用 `⌘⇧L` 转为待办，不必为小事新建项目。
- 项目标题旁的 `…` →「删除项目」会将项目移到已删除列表；侧栏底部垃圾桶可以恢复。正文、格式与事项时间会保留，恢复后的提醒保持关闭，可自行重新开启。「近期」和「随手记」为内置栏目。
- 侧栏底部固定的 `+` 可添加栏目；栏目较多时索引区支持独立滚动。重启后恢复最后选择的栏目。
- 内容和文字格式自动保存在本机，勾选待办、切换栏目和重启后均保留。底部导出按钮或菜单栏「导出便笺」默认导出包含所有栏目的 `.rtf` 富文本；也可以使用 `.txt` 后缀导出纯文本。

### 截止时间、会议和近期汇总

- 在项目或随手记中，将光标放到一行，点格式栏「时间」；也可以在可勾选预览里点行末「设时间」或已有日期。统一面板提供「截止时间 / 会议时间」，默认不提醒。
- **截止时间**：可只选日期，表示当天结束前完成；取消「只设日期」后可选具体时间。普通文字设置截止后自动成为待办，不添加会议标记。提醒可选当天 09:00、前一天 09:00，具体时间的截止还可提前 1 小时提醒。
- **会议时间**：选择开始日期和时间；可在开始时，或提前 5、10、15、30、60 分钟、1 天提醒。也可用「会议」按钮、`⌘⇧M` 或 `#会议 ` 标记暂未定时间的会议。
- 「近期」汇总所有项目和随手记中有时间的任务，以及显式标记的会议。按已逾期、今天、接下来、未定时间分组，组内按时间排列；已过时间的会议与已完成事项默认折叠。无日期的普通任务留在原栏目。旧版「近期会议」自动更名，正文和原会议计划保留。
- 正文、时间、来源项目各自对齐，不使用卡片外框。长标题可以换行，时间和来源保留在右侧；点击正文或来源编辑原文，勾选完成会同步到原项目。点击「继续写」可在近期直接记事，「查看汇总」返回列表。
- 时间和提醒独立保存在本机；修改正文、插入前面的行、切换完成状态会保留绑定。会议与截止类型在时间面板中切换时保留事项身份。清除截止时间后任务留在原栏目；清除会议时间仍保留会议标记。取消会议标记或把截止任务恢复为普通文字会移除相应计划；无法明确归属的批量改写会清除相应时间，避免提醒错行。
- 日期时间按 Mac 当前时区显示；日期文字不会被自动猜测，需在日历中选定。当天提醒固定为本地 09:00，日期截止在次日零点进入逾期；过时会议不会标成任务逾期。
- 首次主动启用提醒时才请求 macOS 通知权限；拒绝后仍可保存日期，之后可在系统设置 → 通知 → NotchNote 中开启。改期替换原通知，完成、删除、关闭提醒或清除时间会撤销通知。已过去的提醒不补发。
- 使用本地系统通知，应用退出前完成同步，点击通知定位原事项。通知受系统权限、专注模式与休眠影响。本功能不读写系统日历，不向服务器发送便笺。

每个栏目独立保存文字和编辑撤销历史，支持自由换行、中文输入、复制粘贴。不与系统「便笺」同步；已有文字可以直接粘贴。编辑时的待办格式为 `- [ ] 内容`，完成后为 `- [x] 内容`。

## 构建

需要 macOS 14+ 和 Swift 6.2+（Xcode 或 Command Line Tools），无需第三方依赖。

```sh
zsh scripts/build-app.sh
open build/NotchNote.app
```

应用默认不显示 Dock 图标，通过菜单栏图标访问或退出。生成的应用使用本机临时签名；此版本尚未做 Developer ID 签名、公证或公开发行。

```sh
zsh scripts/check.sh
zsh scripts/check-motion.sh
zsh scripts/check-meetings.sh
```

回归检查覆盖中文与空行保留、待办切换、持久化、损坏文件保护、写入失败、显示器定位、原生编辑器行转换、富文本格式保存与导出；无需额外安装测试运行器。

窗口检查需要图形桌面会话，会短暂显示测试面板；使用独立的临时便笺数据，验证收起点击区域、反向过渡、键盘中断、栏目撤销隔离、格式选区保持、自动收起与固定/弹窗保护，以及失焦后编辑器第一响应者恢复、修改保存与重读、长文本滚动至末行及删短后的滚动区域收缩。

时间专项检查使用临时文件和模拟通知，覆盖旧计划兼容、日期截止与夏令时提醒、类型切换、分组排序与重启、行编辑后的绑定、改期与取消、权限拒绝、安排失败、原生日期触发器与异步请求竞争；不会弹出权限框或发送真实通知。

## 数据与边界

数据文件：`~/Library/Application Support/NotchNote/note.json`。使用原子写入；保存失败会显示提示，退出前会提醒备份。读取失败时保护原文件，暂停覆盖写入，可以导出当前输入内容后人工修复数据文件。

升级到栏目版时，旧便笺的独立 `【栏目名称】` 行会自动转为索引签，其他正文保留在对应栏目；未分组的文字放入「随手记」。转换前先生成完整原文件备份 `note.v1-<UUID>.json`，再写入新版格式。删除的项目及其事项时间保存在同一文件的已删除列表中，不参与活动项目的待办统计、近期汇总或提醒；恢复操作可跨重启使用。私人便笺数据不进入源码仓库。

优先附着在带刘海的显示器；没有刘海时位于主显示器菜单栏下方。显示器变化时重新定位。速览不激活当前应用，编辑通过原生浮动面板获取键盘输入。快捷键注册失败时提供菜单栏入口。

待实机验收：不同刘海机型、自动隐藏菜单栏、全屏 Space、外接显示器组合与 VoiceOver。当前未实现栏目重命名、开机自启、iCloud 同步和系统便笺导入。
